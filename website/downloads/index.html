Downloads

One static binary, no runtime dependencies. The cloud builds add the S3/GCS/Azure object-store backends (for FireflyCloud on Cloudflare R2 and friends); the gpu builds add wgpu kernels. Checksums are verified by the install script.

Install

MethodCommand
curlcurl -fsSL https://lessdb.dev/install.sh | sh
npmnpm install -g lessdb --registry https://lessdb.dev/npm/  — then lessdb … (or one-shot npx lessdb …)
HomebrewA neutral public tap is not advertised yet; use curl, npm, or cargo.
upgradelessdb upgrade — self-update in place (verify + replace)
cargocargo install --path crates/less-cli (from source; add --features less-cli/cloud for S3/GCS/Azure/R2)

The curl installer picks the right archive for your OS/architecture, verifies SHA-256, and drops lessdb into ~/.local/bin. The npm and brew installers do the same verification against the same artifacts.

Or build from source

From an existing LessDB source checkout:

cargo install --path crates/less-cli            # base
cargo install --path crates/less-cli --features less-cli/cloud   # + S3/GCS/Azure
cargo install --path crates/less-cli --features less-cli/cloud,less-cli/gpu

Verify integrity

shasum -a 256 lessdb-*.tar.gz   # macOS
sha256sum lessdb-*.tar.gz        # Linux

Every archive contains the lessdb binary, LICENSE, and a RELEASE note with the git commit it was built from.
