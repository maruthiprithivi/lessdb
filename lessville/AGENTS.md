# Lessville continuity

EGM artifact directory: docs/egm

Read [EGM.md](EGM.md) and the affected component contract before changing this world.
The parent repository's AGENTS.md and user instructions still apply.

- Prefer the code knowledge graph for discovery; check coverage and read actual
  source when stale/excluded. Contracts are navigation aids, not ground truth.
- Keep the population at five focal and 95 supporting residents unless the user
  changes the requirement. The current town-centre cast is 5 + 12; 83 supporting
  lives continue in surrounding districts. Visual scale must not encode behavioral tier.
- Use `scripts/lessville/world_scale.gd` for art-space proportions. Read
  `docs/WORLD-SCALE.md` before changing human, furniture, prop, dog or vehicle size.
  Preserve feet/hip anchors and distinguish pixel art from metric robot geometry.
- Update component contracts when behavior, interfaces, persistence or scale changes.
  Append dated observations, decisions, checks, evidence paths and open gaps to
  `docs/egm/LEARNING-LOG.md`; preserve failures and later fix evidence.
- Record a run's start/end minute, population, renderer and actual capture timeline.
  A 24-hour simulation run means 1,440 simulated minutes unless explicitly stated otherwise.
- Never present generated proposals as applied agent improvements, scripted needs
  as calibrated human physiology, or passed build checks as completed realism validation.
- Keep runtime worlds, captures, dependency builds and credentials out of source control.
  Local execution uses loopback with remote model and cloud checkpoint integration disabled.
